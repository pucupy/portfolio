## How to use this file

1. The vertical or use case in play
2. The funnel stage (Awareness / Consideration / Evaluation)
3. The persona (where flagged)

For out-of-scope verticals (Edge Case 1), search this file first before asking the user or running a web search on yapily.com.

## Flagged Assets — Validate Before Use

The following asset types have known issues. Validate before including in any output:

| Issue | Action |
|---|---|
| Google Slides decks (internal) | Require Google Workspace access — flag for AE/SDR to check access before sending |
| PDF one-pagers (internal) | Check whether current version is available in the shared drive before referencing |
| Blog posts older than 12 months | Verify URL is still live and content hasn't been superseded |
| Lovable apps | Check app is still live at the URL — these can be updated or taken down |
