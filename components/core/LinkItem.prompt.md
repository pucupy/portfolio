LinkItem — an underlined accent-colored link, with an arrow-out icon and a visually-hidden "(opens in new tab)" suffix for external destinations.

```jsx
<LinkItem href="https://paper.design/">Paper</LinkItem>
<LinkItem href="/about" external={false}>About</LinkItem>
```

Fixes the reference site's icon-only external-link affordance, which has no text alternative for screen reader users.
