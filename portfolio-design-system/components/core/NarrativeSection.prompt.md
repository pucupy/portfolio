The workhorse of every page: an h2 and one or more paragraphs, clamped to the 700px text measure.

```jsx
<NarrativeSection heading="Problem" longLeading>
  <p style={{ margin: '0 0 18px' }}>First paragraph.</p>
  <p style={{ margin: 0 }}>Second paragraph.</p>
</NarrativeSection>
```

Prose colour is always `--ink-2`; only leads and headings are `--ink-1`.
