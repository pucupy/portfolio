# UI kit — portfolio

Two static screens that show the system assembled at full scale:

- `index.html` — home: hero, career timeline, numbered work list (abbreviated to five of eleven entries), footer.
- `case-study.html` — case-study template: eyebrow, hero image, three narrative sections, Decisions blocks, gold Outcomes callout.

Imagery is deliberately shown as labelled reservations (dimensions + object-fit) rather than stand-in photography — the real files belong to the site, and the kit's job is to show the measure, height and rhythm each slot has to hit. Copy is placeholder; the site's own content source is authoritative.

Both screens use only tokens from `styles.css` — no values are hard-coded.
