# Almanac design guidance library

Reference material collected 4 October 2026, distilled for Almanac v3. Load the matching file before designing in that area. The binding rules live in `skills/almanac-design-guardrails/SKILL.md`. Where a file here conflicts with the guardrails, the guardrails win.

| File | Use it when |
|---|---|
| `wcag-design-reference.md` | Any screen. WCAG 2.2 AA is the floor (user-supplied reference, verbatim) |
| `web-interface-guidelines.md` | Interaction, forms, focus, motion, layout and content details |
| `notifications.md` | The Notifications screens, notification settings, emails, toasts |
| `eval-loop.md` | Before handing over any feature: blind critique and scoring |
| `data-density.md` | Portal tables, dashboards, Portfolio, Bureau |
| `motion-and-neurons.md` | Any animation, especially the neuron network |
| `tablets.md` | Tablet portrait and landscape layouts |
| `external-skills.md` | Third-party skill packs worth installing in Claude Code |
| `uploaded-skills/` | The four SKILL files you supplied, kept verbatim |
